4 เรียนอย่างไรให้รอด

✅ สูตรลับได้ A
  1. มาเรียนทุกคาบ เก็บ Quiz ท้ายคาบครบ 60 คะแนน Quiz ท้ายคาบปรึกษาเพื่อนได้ ถามอาจารย์ได้ แค่นี้ปลายภาคต้องการอีกแค่ 20
  2. เปิดเว็บนี้อ่านบทก่อนเข้าคาบ ลองทำแบบฝึกหัดระหว่างเรียนเองก่อนกดดูเฉลย และรัน SQL จริงใน DBeaver ทุกตัวอย่าง
  3. ถึงช่วงตอบเอาโบนัส ยกมือตอบเลย เก็บคะแนนโบนัสจุก ๆ
  4. ก่อนสอบ ทวน สรุปคำสั่ง SQL และทำคำถามท้ายบทให้ครบทุกบท
  5. ไม่เข้าใจตรงไหน รีบทบทวน หรือถามอาจารย์ในชั่วโมงนั้นเลย อธิบายซ้ำได้ แต่ก็ต้องฝึกคิดด้วย อย่าเก็บไว้จนถึงวันสอบ
