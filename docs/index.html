ตัวอย่าง · GROUP BY
-- นับจำนวนนิสิต และเกรดเฉลี่ยของแต่ละสาขา
SELECT major,
       COUNT(*)           AS n_student,
       ROUND(AVG(gpa), 2) AS avg_gpa
FROM   student
GROUP  BY major
ORDER  BY major;

② แบบฝึกหัดระหว่างเรียน — ลองคิดก่อน แล้วค่อยกดดูเฉลย

ฝึก ตัวอย่างสาขาที่มีนิสิตตั้งแต่ 3 คน⭐⭐ ปานกลาง

จงเขียนคำสั่งแสดงชื่อสาขาและจำนวนนิสิต เฉพาะสาขาที่มีนิสิตตั้งแต่ 3 คนขึ้นไป เรียงจากมากไปน้อย

✅ เฉลย
เฉลย
SELECT major, COUNT(*) AS n_student
FROM   student
GROUP  BY major
HAVING COUNT(*) >= 3
ORDER  BY n_student DESC;
▸ ผลลัพธ์ (4 แถว)

เงื่อนไขกับฟังก์ชันรวม (COUNT(*)) ต้องเขียนใน HAVING ไม่ใช่ WHERE เพราะ WHERE ทำงานก่อนการจัดกลุ่ม

③ คำถามท้ายบท

คำถามท้ายบท

  1. จงอธิบายความแตกต่างระหว่าง WHERE กับ HAVING พร้อมยกตัวอย่าง อธิบาย
  2. เหตุใด COUNT(*) กับ COUNT(gpa) จึงให้ผลไม่เท่ากัน วิเคราะห์
  3. จงเขียนคำสั่งแสดงอาจารย์ที่มีเงินเดือนสูงสุด 3 อันดับแรก เขียน SQL
