① Code card — กดปุ่มคัดลอกไปวางใน DBeaver ได้เลย

-- นับจำนวนนิสิต และเกรดเฉลี่ยของแต่ละสาขา SELECT major, COUNT(*) AS n_student, ROUND(AVG(gpa), 2) AS avg_gpa FROM student GROUP BY major ORDER BY major;
⚠️ ข้อควรระวัง

WHERE gpa = NULL จะไม่คืนแถวใดเลย ต้องใช้ IS NULL เสมอ

② แบบฝึกหัดระหว่างเรียน — ลองคิดก่อน แล้วค่อยกดดูเฉลย

จงเขียนคำสั่งแสดงชื่อสาขาและจำนวนนิสิต เฉพาะสาขาที่มีนิสิตตั้งแต่ 3 คนขึ้นไป เรียงจากมากไปน้อย

SELECT major, COUNT(*) AS n_student FROM student GROUP BY major HAVING COUNT(*) >= 3 ORDER BY n_student DESC;

เงื่อนไขกับฟังก์ชันรวม (COUNT(*)) ต้องเขียนใน HAVING ไม่ใช่ WHERE เพราะ WHERE ทำงานก่อนการจัดกลุ่ม

③ คำถามท้ายบท

  • จงอธิบายความแตกต่างระหว่าง WHERE กับ HAVING พร้อมยกตัวอย่าง อธิบาย
  • เหตุใด COUNT(*) กับ COUNT(gpa) จึงให้ผลไม่เท่ากัน วิเคราะห์
  • จงเขียนคำสั่งแสดงอาจารย์ที่มีเงินเดือนสูงสุด 3 อันดับแรก เขียน SQL
